# Suki Doces - Organization

📌 Sobre o Projeto

O Suki Doces é uma plataforma online desenvolvida para facilitar a compra de doces artesanais de forma simples, intuitiva e agradável.
O sistema permite que clientes naveguem por um catálogo organizado, escolham seus produtos preferidos, adicionem ao carrinho e finalizem a compra com opções de pagamento digitais.

O objetivo é modernizar a experiência de compra, unindo praticidade, design atrativo e funcionalidades essenciais para um e-commerce.

🎯 Objetivos

Disponibilizar um catálogo digital de doces com imagens, descrições, preços e disponibilidade.

Oferecer busca e filtros inteligentes por categoria, preço ou tipo de doce.

Implementar um carrinho de compras funcional, com cálculo automático do valor total.

Garantir pagamentos seguros através de métodos digitais.

Criar uma interface responsiva que funcione em computadores, tablets e celulares.
